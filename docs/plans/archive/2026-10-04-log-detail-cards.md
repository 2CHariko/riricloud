# 日志详情信息卡片化与元数据降噪

## 目标与边界

按用户截图将详情连续文字改为时间、来源归属、实例关联、采集计数卡片；正文优先、原始 JSON 默认收起。保留完整证据、复制、过滤、未知字段与非法原文，不将采用 Agent 时间/零采集损失当作健康。只改 Web 展示及对应测试/文档，无依赖/API/数据库/Server/Agent 变更，不改列表密度和全局 UI 原子样式。

当前 fix/web-log-detail-cards 基于先前基线提交 53b04a1；上一轮未提交的日志页紧凑布局全部保留，不自动提交或推送。共用 LogCorrelation 卡片化使节点/日志诊断快照结果证据同步受益，不修改任务请求、截止、能力或观察逻辑。
