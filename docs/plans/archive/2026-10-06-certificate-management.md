# 手动证书管理完善

完善手动证书生命周期：不改 ACME/反向代理，不增加 Agent 协议字段、真实握手或外部服务。允许自签名/私有 CA，明确公信任未验证。版本保留当前及最近十个历史版，手动整体回滚；过期/域名不匹配允许入库但阻止新绑定/替换。提醒默认30天，邮件关闭且每日汇总，失败6小时重试。分发复用回执/心跳，离线等待、120秒超时（HTTP至少三轮询周期）、迟到确认、旧回执隔离。

- [x] 版本及分发：修订/并发/预览/回滚、持久配置依赖和回执心跳对账
- [x] 到期提醒：管理员入口、可选邮件、持久去重/续期失效

验收覆盖错误链顺序/签名/私钥、SAN通配符/IP/桥接、过期/未来、并发/历史保留/回滚、WS/HTTP/离线/重启/超时/旧Agent/高级覆盖、邮件去重与失败、权限/日志无秘密、超过100条选择、草稿回归。历史异常不自动停线。视觉走查仅 Antigravity 按需执行。

实现及验证：追加迁移在隔离 SQLite 顺序执行；证书生命周期轻量 Nest HTTP E2E 使用真实 JWT/RBAC/Prisma，WS socket 与 HTTP poll 复用现有 AgentService。`scripts/dev-e2e*` 未消费证书字段或修订接口，启动/Agent 消息字段不变无需改动，现有脚本回归已核对并通过。全部本地验收使用 Windows Git Bash、本机 Node/Go，不使用 WSL；未执行浏览器视觉走查，已维护 UI-26 索引。

## 第一阶段：校验与管理体验

- PEM 支持叶子及 fullchain（可省略根），全部可解析、无重复，相邻签发关系及签名正确，叶子与私钥匹配；接受自签名/私有 CA，不联网补链，链内部验证不代表公信任。
- 有效期、链校验和信任说明分别展示，提供 SHA-256 指纹、密钥类型、链长度及各级信息；过期/尚未生效可以保存。
- 复用订阅实际端点/SNI 规则检查域名、单层通配符与 IP SAN；通配符仅是覆盖范围，不回填为客户端 SNI，普通域名可建议。
- 新绑定、启用及已绑定内容替换必须合格，替换检查全部关联和桥接线路；历史问题仅标记，改名、停用和解除关联不阻断。
- 关联明细分页展示名称、协议、状态、节点、实际 SNI、匹配及线路跳转；区分关联节点和承载节点。
- 列表默认每页 20，状态/关联筛选与到期排序；选择器服务端搜索分页，避免前 100 条截断。重复叶子提示已有记录但仍可保存；失败可重试，删除引用展示关联明细。

## 第二阶段：版本与分发生效追踪

- 保留 Certificate ID 和 Line.certificateId，新增修订、内容摘要及 CertificateRevision；仅内容变化建版本和推送，改名/重复保存不推送。当前外保留十个历史版，私钥 AES-GCM，历史 API 仅元信息，回滚生成新修订。
- 更新前展示新旧有效期、SAN 覆盖和受影响线路；保存重新校验，短事务提交。expectedRevision 可选，新 UI 必交，冲突 409。
- 分发持久化修订、节点、目标配置版本及结果，依赖最终 Agent 配置生成内容；高级覆盖标记“未由证书中心控制”，盲转发入口不承载证书。
- 复用 config_apply_result、appliedConfigVersion、kernelRunning；等待/发送/接受/运行确认/失败/超时/替代分开，HTTP 实际返回配置才记发送。
- 运行确认必须对应快照包含目标修订且内核存活，后续配置仍使用同一修订可以确认，旧回执不覆盖新目标；旧 Agent 缺少运行字段显示无法确认。
- 在线发送后 120 秒超时，HTTP 取与三倍轮询间隔较大值；不自动回滚，迟到心跳可确认；离线等待，重连及 Master 重启继续对账。
- 失败节点可重试，整体回滚校验历史内容和全部当前关联线路后同步所有当前承载节点；不支持节点长期分叉版本。页面明确保存与运行确认的区别和 Sing-box 重启可能性。

## 第三阶段：提醒

- 管理员证书页与侧栏展示需处理汇总，不发布用户公告；默认阈值 30，可配 1～90 天。
- 启动延迟检查，其后每小时，单并发、定时器可退出，不增加外部队列。
- 邮件默认关闭且收件人为空，开启校验可用 SMTP 和合法收件人；按站点时区每日最多一次汇总，覆盖阈值/7 天/1 天/过期。
- 按修订、阶段、收件人持久记录，成功标记、失败六小时后重试，续期使旧提醒失效；SMTP 不保证严格恰好一次，邮件不含 PEM/私钥。

## 第四阶段：导出与审计

- leaf/fullchain/private-key/bundle POST 下载，秘密格式界面确认，统一 API 客户端、管理员鉴权、no-store；响应与临时秘密不写日志。
- 系统日志记录创建、改名、替换、回滚、删除、详情私钥读取、导出、重试及分发失败，含操作者、ID、修订与结果，禁止秘密；详情跳对应日志，沿用保留与完整性限制。

## 接口与兼容

新增接口均为 `/api/v1/admin/certificates` 的管理员接口：`GET /summary`、`GET /:id/lines`、`GET /:id/revisions`、`GET /:id/deployments`，以及 `POST /:id/preview-update`、`POST /:id/rollback`、`POST /:id/deployments/retry`、`POST /:id/export`。列表新增状态/关联/排序，解析与详情新增链/指纹/校验/修订，旧字段保留。系统设置新增阈值/邮件开关/收件人。追踪字段仅存 Master，Agent 消息不变。

只追加迁移，不改历史迁移/清库；历史首次访问或巡检幂等建立初始修订，异常保留内容并标记，不自动推送或停线。API、模型、架构、部署、UI 文档与 Unreleased 同步，版本不变。
