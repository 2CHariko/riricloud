# 手动证书管理完善

完善手动证书生命周期：不改 ACME/反向代理，不增加 Agent 协议字段、真实握手或外部服务。允许自签名/私有 CA，明确公信任未验证。版本保留当前及最近十个历史版，手动整体回滚；过期/域名不匹配允许入库但阻止新绑定/替换。提醒默认30天，邮件关闭且每日汇总，失败6小时重试。分发复用回执/心跳，离线等待、120秒超时（HTTP至少三轮询周期）、迟到确认、旧回执隔离。

- [x] 校验与查询：链/私钥/SAN、关联线路/节点、分页筛选与历史兼容
- [x] 版本及分发：修订/并发/预览/回滚、持久配置依赖和回执心跳对账
- [x] 到期提醒：管理员入口、可选邮件、持久去重/续期失效
- [x] 导出与审计：叶子/fullchain/私钥/包、鉴权/no-store/操作日志
- [x] 前端中文词条、文档/视觉索引与 E2E 消费者同步
- [ ] 回归测试、完整门禁、PR/CI 与归档

验收覆盖错误链顺序/签名/私钥、SAN通配符/IP/桥接、过期/未来、并发/历史保留/回滚、WS/HTTP/离线/重启/超时/旧Agent/高级覆盖、邮件去重与失败、权限/日志无秘密、超过100条选择、草稿回归。历史异常不自动停线。视觉走查仅 Antigravity 按需执行。

实现及验证：追加迁移在隔离 SQLite 顺序执行；证书生命周期轻量 Nest HTTP E2E 使用真实 JWT/RBAC/Prisma，WS socket 与 HTTP poll 复用现有 AgentService。`scripts/dev-e2e*` 未消费证书字段或修订接口，启动/Agent 消息字段不变无需改动，现有脚本回归已核对并通过。全部本地验收使用 Windows Git Bash、本机 Node/Go，不使用 WSL；未执行浏览器视觉走查，已维护 UI-26 索引。
